# PRCJ Frontend

React JavaScript frontend powered by Vite and Tailwind CSS.

## Stack
- React (JavaScript)
- React Router
- Tailwind CSS

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run start
```

## Environment
- `VITE_API_URL` (default: `http://localhost:8000/api/v1`)
- `VITE_RAZORPAY_KEY_ID`
